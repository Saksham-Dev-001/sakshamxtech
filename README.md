# SakshamXTech 🚀

> The all-in-one developer platform for Google Cloud Arcade 2026, Unstop POTD solutions, C Academy, Tech Blogs, Hackathons, Internships, and Free Swags.

![SakshamXTech Banner](/public/assets/branding/saksham_avatar.png)

---

## ✨ Features

- **Google Cloud Arcade 2026 Hub**: Complete walkthroughs for Skill Badges, Trivia, Points Calculator, Prize Tiers (Trooper, Ranger, Champion, Legend), and Swag drop tracker.
- **Unstop Problem of the Day (POTD)**: Daily updated optimal solutions in C, C++, and Python with complexity analysis and interactive code runner.
- **C Academy**: Structured C programming roadmap, complete syllabus, chapter notes, and an integrated in-browser interactive C compiler.
- **Tech Blogs & Guides**: In-depth tutorials, developer roadmaps, and certification guides with YouTube video integrations.
- **Opportunities Portal**: Curated hackathons, internships, hiring challenges, and student programs with verified links.
- **Verified Tech Swags**: Real-time drop announcements and claim guides for Google, Microsoft, and tech community swags.
- **Firebase Firestore Cloud First**: Powered by Google Cloud Firestore with real-time bidirectional 2-way listeners, automatic synchronization, and self-healing data.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Motion
- **Database & Cloud**: Google Cloud Firestore (Firebase v13)
- **Deployment**: Vercel ready with custom rewrite configuration

## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd sakshamxtech
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
The application will be running locally at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com/) and click **Add New > Project**.
3. Import your `sakshamxtech` GitHub repository.
4. Framework Preset: **Vite**.
5. Click **Deploy**! (The included `vercel.json` ensures all client-side routes rewrite seamlessly).
